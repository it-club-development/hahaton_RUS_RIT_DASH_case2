# Мотив · Веб-отчётность

## Запуск в Windows

Установите Node.js 22.12 или новее с npm. Откройте PowerShell в папке `frontend` рядом с `package.json`.

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте адрес из терминала. Обычно это http://localhost:5173. Остановить сервер можно сочетанием Ctrl+C. В терминале без ограничений PowerShell можно использовать `npm` вместо `npm.cmd`.

Демонстрационный вход: `admin`, `duty` или `engineer`. Пароль для каждого логина — `demo`.

## Папки

- `src/pages/MainPage/` — «Отчётность», фильтры, таблица и статистика.
- `src/pages/IncidentPage/` — создание и редактирование аварии.
- `src/pages/LoginPage/` — форма входа.
- `src/App.tsx` — шапка, профиль, переходы и состояние приложения.
- `src/data.ts` — типы, расчёты и демонстрационные данные.
- `src/styles.css` — общие стили.

В каждой папке страницы есть свой файл `.tsx` с компонентом React и файл `.css` со стилями.

## Сборка

```powershell
npm.cmd run build
npm.cmd run preview
```

Готовые файлы появятся в `dist/`. Для Chrome 75 проверяйте собранную версию через preview. Сервер разработки предназначен для современного браузера.

Записи и демонстрационный вход хранятся в браузере. При переходе с локального HTML на localhost данные будут храниться отдельно. Серверное API пока не подключено.
